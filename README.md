## Projects

### 1. Personal Profile Card

A responsive personal profile card built using vanilla HTML, CSS and JavaScript.

**Features**
- Personal profile presentation
- Responsive layout
- Interactive GitHub profile link
- Availability indicator

**Technologies:** HTML5, CSS3, JavaScript

[View Project](./html-css/profile-card/)

### 2. Shopping Cart Application

A simple interactive shopping cart demonstrating core JavaScript programming concepts.

**Features**
- Add and remove products
- Product input validation
- Automatic price calculations
- Dynamic product rendering
- Empty cart handling
- Browser data persistence using localStorage

**Technologies:** HTML5, CSS3, JavaScript, JSON, Web Storage API

[View Project](./html-css/shopping-cart/)
